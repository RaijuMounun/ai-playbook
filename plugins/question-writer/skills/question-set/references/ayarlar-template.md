# Template for `ayarlar.md`

On first use, create `ayarlar.md` in his work folder from the block below, after filling in his answers. The file is his: write it in Turkish and keep it short. Later sessions read it before anything else.

```markdown
# Soru yazım ayarları

## Seçenek sayısı
- 2. sınıf: 3 seçenek (A, B, C)
- 3. sınıf: 3 seçenek (A, B, C)
- 4. sınıf: 4 seçenek (A, B, C, D)

## Yayınevi kuralları
- (Yayınevinin özel kuralları varsa buraya yazılır. Örnek: "Olumsuz ifadenin altı çizilir.")

## Teslim
- Word şablonu: sablon.docx
- Başlık: <YAYINEVİ> <N>. SINIF TÜRKÇE <M>. DENEME
- Bir sette soru sayısı: 15
- Her soru mümkünse farklı bir öğrenme çıktısını ölçer. Liste yetmezse tekrar edilebilir.
- Cevap: soru kökünün altında harf üç kez yazılır (örnek: BBB).
- Öğrenme çıktısı: şıkların altında, kodu ve metniyle yazılır.

## Görseller
- Görselleri kim hazırlıyor: (kendim yerleştiriyorum / yayınevinin çizeri çiziyor)

## Üslup notları
- (Beğendiği ve beğenmediği şeyler, zamanla eklenir.)
```

When he states a lasting preference ("şıklar hep kısa olsun", "çocuk isimleri farklı olsun"), offer to add it under "Üslup notları" so later sets keep it.
