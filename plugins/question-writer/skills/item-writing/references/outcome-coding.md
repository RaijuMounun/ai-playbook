# Learning outcome codes and where to find them

## Code format

The İlkokul Türkçe Dersi Öğretim Programı (Türkiye Yüzyılı Maarif Modeli) codes outcomes as `T.<area>.<grade>.<number>`:

- `T`: Türkçe
- area: `D` Dinleme/İzleme, `K` Konuşma, `O` Okuma, `Y` Yazma
- grade: 1-4
- number: the outcome's number within that area and grade

Examples: `T.O.3.2` is grade 3 reading, outcome 2. `T.Y.2.1` is grade 2 writing, outcome 1.

Each outcome has process components ("süreç bileşenleri"), lettered `a)`, `b)`, `c)`, `ç)`, `d)` and so on. An item targets one component. Write it as `T.O.3.2 b)` in the plan.

A multiple-choice item can test:
- reading outcomes
- listening outcomes, with a transcript the teacher reads aloud
- some writing outcomes, through spelling and punctuation choices

It cannot test speaking. If he gives a speaking outcome (`T.K.…`), say so and ask whether to swap it for another outcome.

## Where the official list is

- **Program PDF** (2026 cover): https://mufredat.meb.gov.tr/Dosyalar/202681493354625-Türkçe%20(1-4)%20DÖP%20TTKB.pdf
- **Fastest lookup:** EK 1 on page 202, "Sınıf Düzeylerine Göre Öğrenme Çıktıları ve Süreç Bileşenleri". The grade sections start at page 70 (grade 2), page 112 (grade 3) and page 154 (grade 4).
- **The PDF's text is partly garbled** because of its font encoding, so Turkish characters may come out wrong. Restore the wording carefully. When in doubt, ask him to check it against his own copy.
- **The version is unconfirmed.** It is not known whether this PDF replaces the May 2024 program. If he works from a different version, his version wins.

## Order of preference

1. The outcomes he gives for the set. He knows what the publisher ordered.
2. The program PDF in his work folder (`program/`), if he put one there.
3. The URL above, read directly, only if he asks to look the outcomes up and has no copy.

Never invent an outcome or a code. If you cannot find an outcome, say so and ask him.
