# Learning outcome codes and where to find them

## Two programs are in use at once

The Türkiye Yüzyılı Maarif Modeli replaces the 2019 Türkçe program one grade at a time. In the 2026-2027 school year:

- **Grades 2 and 3** use the Maarif program. Its outcomes are "öğrenme çıktıları" and the codes look like `T.O.3.3.b)`.
- **Grade 4** still uses the 2019 program. Its outcomes are "kazanımlar" and the codes look like `T.4.3.28.`.

The evidence is a publisher's 2026-2027 outcome lists, which use these two formats. When grade 4 moves to Maarif (expected the following school year, not verified), the codes he gives will change, and his codes always win. Always use a code exactly as he gives it. Never convert one format into the other, and never add a process-component letter to a grade 4 code.

## Maarif codes (grades 2-3)

Format: `T.<area>.<grade>.<number>.<component>)`:

- `T`: Türkçe
- area: `D` Dinleme/İzleme, `K` Konuşma, `O` Okuma, `Y` Yazma
- grade: the class level
- number: the outcome's number within that area and grade
- component: the process component ("süreç bileşeni"), lettered `a)`, `b)`, `c)`, `ç)`, `d)` and so on

Examples: `T.O.3.3.b) Okuduğu metnin konusunu bulur.` and `T.Y.2.3.ğ) Yazılarında noktalama işaretlerini kuralına uygun kullanır.` An item targets one process component, and he writes the code together with the component text.

## 2019 codes (grade 4 for now)

Format: `T.<grade>.<area>.<number>.`, where area `1` is Dinleme/İzleme, `2` Konuşma, `3` Okuma and `4` Yazma. Examples: `T.4.3.28. Okudukları ile ilgili çıkarımlar yapar.` and `T.4.4.10. Büyük harfleri ve noktalama işaretlerini uygun yerlerde kullanır.` There are no process components. Some broad kazanımlar (çıkarım, metinle ilgili sorular) are used for several items in one set.

## What multiple choice can test

- reading outcomes
- listening outcomes, with a transcript the teacher reads aloud
- writing outcomes through recognition: spelling, capital letters, punctuation, word order, word choice, completing a text

Speaking (`T.K.…`, `T.4.2.…`) cannot be tested this way. If he gives a speaking outcome, say so and ask which outcome to use instead.

## Where the official lists are

- **Maarif program PDF** (grades 1-4, 2026 cover): https://mufredat.meb.gov.tr/Dosyalar/202681493354625-Türkçe%20(1-4)%20DÖP%20TTKB.pdf. EK 1 on page 202 lists the outcomes and process components by grade. The PDF's text is partly garbled when read, so restore the Turkish characters carefully.
- **2019 Türkçe program (grade 4):** use the publisher's kazanım list, or the copy in his work folder. Do not look it up on the web unless he asks.

## Order of preference

1. The outcomes he gives for the set. He knows what the publisher ordered.
2. A program file or outcome list in his work folder (`program/`).
3. The Maarif PDF above, read directly, only if he asks to look outcomes up and has no copy.

Never invent an outcome or a code. If you cannot find an outcome, say so and ask him.
