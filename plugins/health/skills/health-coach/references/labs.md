# Lab results

Sources checked 2026-11-13.

## Start with

| Source | Use for |
| :- | :- |
| MedlinePlus, Medical tests (US National Library of Medicine), https://medlineplus.gov/lab-tests/ | What each test measures and why it is ordered. Neutral and lay-facing. |
| ESC/EAS: 2025 focused update of the 2019 guidelines for dyslipidaemias (Mach et al., Eur Heart J, 2025), https://doi.org/10.1093/eurheartj/ehaf190 | LDL and lipid targets by risk. Check the 2026 erratum before quoting numbers. |
| ADA, Standards of Care in Diabetes—2026, https://doi.org/10.2337/dc26-sint | Glucose and HbA1c. |
| KDIGO 2024 guideline for chronic kidney disease, https://doi.org/10.1016/j.kint.2023.10.018 | Creatinine, eGFR, albuminuria. |
| Endocrine Society, Vitamin D for the prevention of disease (2024), https://doi.org/10.1210/clinem/dgae290 | Vitamin D testing and supplements for prevention, not for treating deficiency. |

testing.com (the former Lab Tests Online) is commercial and sells tests. Use MedlinePlus instead.

## How to explain a result

- Compare each value with the reference range printed on that lab's report. Ranges differ between labs and methods.
- One value just outside the range is often not a disease. Look at the trend, the related values, and the person's age, sex, medications and symptoms.
- Targets for some values (LDL above all) depend on the person's overall risk: age, family history, smoking, blood pressure, diabetes. Use the profile.
- "Optimal ranges" sold by wellness sites are not clinical ranges. Say so if the user brings them.

## Ask first, if not known

- The value with its unit, the lab's reference range, and the date.
- Fasting or not, recent illness or hard training (these move some values), medications and supplements.
- Whether a doctor has already commented on it.

## Topic red flags

A value the lab marks as critical, a doctor's request to come in, or an abnormal value together with symptoms (chest pain, severe weakness, confusion, signs of very high blood sugar). These go to a doctor the same day.
